# Changelog

All notable changes to this project are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow [Semantic Versioning](https://semver.org/); see the "Versioning" section of the README for what each bump means.

## [1.0.0] - 2026-11-12

First versioned release.

### Added
- `CLAUDE.md`: 49 numbered rules for general software development with Claude Code (communication, before starting, documentation, subagents, Git and safety, quality, UI/UX process, proportionality, critique and decisions) and a UI/UX design standards appendix.
- `README.md`: philosophy, rule summary, two Mermaid diagrams (task flow and subagent choice), documentation layout, install and adaptation notes, context cost and modular use, and a note on enforcing the safety rules with permission rules.
- This changelog and the versioning policy.

### Changed
- License changed from MIT to CC BY 4.0, so that reuse requires attribution. Commits up to `a6da19c` were published under MIT.
